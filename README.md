# Orion Project: God of Random v1.8.6

Криптографически стойкий генератор паролей ("откровений") на Python.

## Основные фишки:
* **Уровни сложности:** "Детский сад" (цифры), "Мужик" (буквы+цифры), "Хардкор" (полный фарш).
* **Безопасность:** Авто-очистка буфера обмена Windows через 45 секунд.
* **Скрытность:** Пароль автоматически маскируется звездочками при сворачивании окна.
* **Чистота:** Принудительный вызов `gc.collect()` для очистки оперативной памяти.

## Как запустить:
1. Установи зависимости: `pip install customtkinter pyperclip`
2. Запусти файл: `python main.py`
